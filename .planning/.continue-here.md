<decisions_made>

- Field/property/API name is `user_barcode`; DB column is `storelocations.user_barcode`.
- Length is 255 to permit a portable full-field unique index on all supported DBs.
- Only `''` becomes `NULL`; leading/trailing and whitespace-only content remains opaque and unchanged, matching the existing PartLot form's no-trim convention.
- Scanner priority is internal barcode, then existing `PartLot.user_barcode`, then `StorageLocation.user_barcode`, then the pre-existing remaining formats. A PartLot collision therefore keeps its old behavior.
- Lookup is a targeted repository DQL query, never an in-memory scan.
- Late binding is intentionally deferred because the current unknown-code path throws and renders only a flash; implementing selection/state transfer would require a new UI flow rather than a compact extension point.

</decisions_made>
